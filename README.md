## How to Deploy (Vercel — No GitHub needed)

1. Go to [vercel.com](https://vercel.com) → Sign in (free)
2. Click **Add New...** → **Project**
3. Click the **Upload** tab
4. ZIP the project folder (`src/`, `public/`, `index.html`, `package.json`, `vercel.json`, `.gitignore`)
5. Drag the ZIP into Vercel → Click **Deploy**
6. Get your live link in ~60 seconds
